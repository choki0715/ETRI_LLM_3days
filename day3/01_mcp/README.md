# 실습 · MCP 서버 하나 붙이기 (1세션 · 20분)

Day 2 `loop.py`의 두 도구 — 한빛정밀 사내 자료 검색(`search_docs`)과 계산기(`calculator`) — 를 담은 MCP 서버 **hanbit-docs**를 띄우고, 같은 서버를 두 가지 클라이언트로 씁니다.

- **(1) 내가 만든 파이썬 클라이언트** — `mcp_client.py`가 서버에서 도구를 받아 모델(Claude API)에게 주고, 모델이 고른 도구를 서버에 실행시킨다
- **(2) Claude Code** — `claude mcp add`로 같은 서버를 붙인다

어제 `loop.py`의 `search` 도구는 우리가 짠 루프 안에서만 쓸 수 있었습니다. 같은 일을 **MCP 서버**로 떼어 내면 Claude Code 같은 다른 프로그램이 그대로 붙여 쓸 수 있습니다 — 그게 MCP입니다.

| 파일 | 역할 | 하는 일 |
|---|---|---|
| `hanbit_mcp.py` | **서버** | 도구 둘 — `search_docs(query)` · `calculator(a, b, op)` — 을 `http://127.0.0.1:9800/mcp`에 열어 두고 기다린다. 불릴 때마다 화면에 `[호출]` 기록을 찍는다 |
| `check_server.py` | 클라이언트 (사람이 고름) | 서버에 접속해 도구 목록을 보고, 내가 넣는 검색어 · 계산식으로 도구를 부른다 — 모델 없음 |
| `mcp_client.py` | **클라이언트 (1)** | 서버의 도구를 모델(Claude API)에게 주고, **모델이 고른 도구**를 서버에 실행시킨다 — Day 2 `loop.py`와 같은 루프 |
| Claude Code | **클라이언트 (2)** | `claude mcp add --transport http …`로 같은 서버를 붙인다 |
| `mcp_only_hanbit.json` | Claude Code 설정 | hanbit-docs **하나만** 켜고 Claude Code를 띄울 때 쓴다 (6번) |

**서버와 클라이언트를 따로 띄웁니다.** 터미널을 두 개 엽니다.

```
터미널 1                                  터미널 2
hanbit_mcp.py  ◀──── HTTP (MCP) ────  (1) mcp_client.py  ── Claude API
(서버 — 켜 둔다)                          (2) Claude Code
                                          (클라이언트 — 접속해서 부른다)
 [호출] 기록이 여기 찍힌다
```

## 1. 코드 읽기 (3분)

**목표** — 서버와 클라이언트가 각각 무엇을 하는지, 모델이 보게 될 정보가 어디 있는지 안다.

**`hanbit_mcp.py` (서버)** — 네 군데를 봅니다.

| 볼 곳 | 뜻 |
|---|---|
| `LONG` · `SHORT` · `WRONG` · `CALCULATOR_DESCRIPTION` | **도구 설명** — 모델은 이것만 보고 언제 어떤 도구를 부를지 고른다. 어제 `loop.py`의 `description`과 같은 자리. search_docs의 설명은 서버를 띄울 때 환경변수 `MCP_DESC`로 셋 중 하나를 고른다 (없음 → LONG, `short` → SHORT, `wrong` → WRONG). 계산기 설명은 늘 같다 |
| `@mcp.tool(...)` 아래 `def search_docs(query: str)` · `def calculator(a: float, b: float, op: Literal[...])` | **함수 이름이 도구 이름, 타입 힌트가 입력 스키마** — `Literal["add", "sub", "mul", "div"]`은 op에 넣을 수 있는 값을 넷으로 정한다 (Day 2의 `enum`) |
| `HOST` · `PORT` · 맨 아래 `mcp.run(transport="streamable-http", ...)` | 서버를 **HTTP로 열어 두고 접속을 기다린다** — 그래서 따로 띄울 수 있다 |
| 문서를 고치는 도구가 없다는 주석 | **쓰는 도구는 만들지 않았다.** 되돌릴 수 없는 행동은 MCP로 노출하지 않고 사람에게 남긴다 |

**`check_server.py` (사람이 고름)** — `SERVER_URL`로 접속해서 접속 → 인사 → 도구 목록을 받은 뒤, `12 * 365` 같은 계산식이면 calculator를, 나머지는 search_docs를 부릅니다. 모델은 없습니다.

**`mcp_client.py` (클라이언트 1)** — Day 2 `loop.py`와 나란히 놓고 봅니다.

| | Day 2 `loop.py` | `mcp_client.py` |
|---|---|---|
| 도구 정의 | 파일에 직접 적었다 (`TOOLS`) | **서버에서 받아 온다** (`session.list_tools()` → `mcp_tools_to_claude_tools`) |
| 도구 실행 | 우리 함수가 했다 (`call_tool` → `calculator()` · `search()`) | **서버에 부탁한다** (`session.call_tool(...)`) |
| 어떤 도구를 쓸지 | 모델이 골랐다 | 모델이 고른다 — 똑같다 |
| 루프 | 모델 호출 → 도구 요청이면 실행 → 결과를 붙여 다시 | 똑같다 |

Claude Code가 MCP 서버를 쓸 때 속에서 하는 일이 바로 `mcp_client.py`입니다.

**확인** — 짝에게 "모델이 도구에 대해 아는 건 무엇무엇인가?"를 말로 설명해 봅니다. (답: 도구마다 이름 · 설명 · 입력 스키마 — 셋뿐)

## 3. 터미널 2 — 도구를 직접 골라 부르기: `check_server.py` (3분)

**목표** — 서버에 접속해서 모델이 보게 될 정보(도구마다 이름 · 설명 · 스키마)를 보고, **어떤 도구를 무슨 값으로 부를지 내가 정해서** 불러 본다. 모델은 없다.

```bash

$PY check_server.py

**터미널 2에 나오는 것** — 먼저 도구 목록을 보여 주고 검색어를 기다린다

```

회사 규정, 금액 기준, 절차, 담당자, 제품 수치를 물을 때 쓴다.
판단은 하지 않는다 — 찾은 원문만 돌려준다. query는 찾을 내용(문서에 쓰였을 법한 말로).

**확인**
- 검색어를 넣을 때마다 터미널 1에 `[호출]` 줄이 생기나 — 클라이언트의 요청이 서버로 가서 실행된다

## 4. 터미널 2 — 모델이 도구를 고르게: `mcp_client.py` (3분)

**목표** — 서버의 도구 둘을 모델에게 주고, **모델이 질문에 맞는 도구를 스스로 골라** 서버에 실행시키는 것을 본다. 루트 `.env`의 API 키를 쓴다.

```bash
$PY mcp_client.py "서울로 출장 가면 숙박비는 하루 얼마까지 나와?" "AX-2041 10대와 AX-2014 5대를 한 상자에 담으면 무게가 모두 몇 kg이야?" "1,234,500원을 3명이 똑같이 나누면 1명당 얼마야?"
```

질문을 안 주고 `$PY mcp_client.py`만 치면 질문을 계속 입력받습니다 (빈 줄이면 끝).

**터미널 2에 나오는 것** (강사가 돌려 봤을 때 · Haiku 5.5, 요약)

```
서버 hanbit-docs 에 접속 — 받아 온 도구:
  search_docs: 가상 회사 한빛정밀의 사내 규정 · 안내문 · 제품 사양서 20편에서 질문과 관련
  calculator: 두 숫자의 사칙연산을 정확히 계산한다. 금액 · 수량 · 무게 · 날짜 수 계산은 …
모델: claude-haiku-5-5
======================================================================
Q 서울로 출장 가면 숙박비는 하루 얼마까지 나와?
[0] 도구 요청: search_docs {'query': '출장 숙박비 한도 서울'}  → MCP 서버에 call_tool
A 서울 출장 숙박비는 1박 15만원까지 나옵니다. …
======================================================================
Q AX-2041 10대와 AX-2014 5대를 한 상자에 담으면 무게가 모두 몇 kg이야?
[0] 도구 요청: search_docs {'query': 'AX-2041 무게'}  → MCP 서버에 call_tool
[0] 도구 요청: search_docs {'query': 'AX-2014 무게'}  → MCP 서버에 call_tool
[1] 도구 요청: calculator {'a': 1.2, 'b': 10, 'op': 'mul'}  → MCP 서버에 call_tool
[1] 도구 요청: calculator {'a': 3.4, 'b': 5, 'op': 'mul'}  → MCP 서버에 call_tool

Q 1,234,500원을 3명이 똑같이 나누면 1명당 얼마야?
[0] 도구 요청: calculator {'a': 1234500, 'b': 3, 'op': 'div'}  → MCP 서버에 call_tool
A 1명당 411,500원이에요.
```

`[0]` `[1]` `[2]`는 몇 번째 모델 호출인지입니다. 무게 질문은 **검색 → 곱셈 → 덧셈**을 시도 세 번에 나눠 했습니다 — 무게를 알아야 곱하고, 곱해야 더할 수 있으니까.

**터미널 1에 새로 찍힌 것** — 모델이 고른 도구와 값이 그대로 보인다

```
[호출] search_docs(query='AX-2041 무게') → 3개 [...]
[호출] search_docs(query='AX-2014 무게') → 3개 [...]
[호출] calculator(a=1.2, b=10.0, op='mul') → 12.0
[호출] calculator(a=3.4, b=5.0, op='mul') → 17.0
[호출] calculator(a=12.0, b=17.0, op='add') → 29.0
[호출] calculator(a=1234500.0, b=3.0, op='div') → 411500.0
```

같은 명령에 질문 `오늘 점심 메뉴 추천해줘`도 넣어 봅니다 — 도구를 하나도 안 부르고 바로 답한다 (터미널 1에 아무것도 안 찍힌다).

**확인**
- 도구 정의를 `mcp_client.py`에 한 줄도 적지 않았는데, 모델이 `search_docs` · `calculator`를 알고 골랐다 — 서버에서 받아 왔기 때문이다
- **질문에 따라 고른 도구가 다르다** — 숙박비는 검색만, 나눗셈은 계산기만, 무게는 둘 다
- 검색어 · 숫자는 우리가 정하지 않았다. **모델이 질문을 보고 만들었다** (3번에서는 사람이 넣었다)

**안 되면** — `서버에 접속하지 못했다`면 터미널 1의 서버를 본다. `Could not resolve authentication method`면 루트 `.env`의 `ANTHROPIC_API_KEY`를 본다. `LLM_MOCK=1`이면 이 클라이언트는 돌지 않는다 (`.env`에서 0으로).

# (2) Claude Code에 MCP로 추가하기

같은 서버를 이번에는 Claude Code에 붙입니다. 4번에서 우리가 짠 일(도구 목록 받기 → 모델에게 주기 → 요청하면 서버에 실행 부탁)을 Claude Code가 대신 합니다.

## 5. 터미널 2 — Claude Code에 등록 (2분)

**목표** — "이 주소에 MCP 서버가 있다"를 Claude Code 설정에 적는다. 서버(터미널 1)는 켜 둔 채로.

```bash
mkdir -p ~/mcp-lab && cd ~/mcp-lab
claude mcp add --transport http hanbit-docs http://127.0.0.1:9800/mcp
claude mcp list
```

**화면에 나오는 것**

```
Added HTTP MCP server hanbit-docs with URL: http://127.0.0.1:9800/mcp to local config

Checking MCP server health…
hanbit-docs: http://127.0.0.1:9800/mcp (HTTP) - ✔ Connected
```

**확인** — `hanbit-docs … ✔ Connected`가 보이는가. 다른 서버가 함께 보여도 괜찮다.

| 명령의 부분 | 뜻 |
|---|---|
| `--transport http` | 서버에 **주소로 접속**한다 — 서버는 터미널 1에 따로 떠 있다 |
| `hanbit-docs` | Claude Code 안에서 부를 서버 이름. 도구는 `mcp__hanbit-docs__search_docs`라는 이름으로 보인다 |
| 범위(기본 `local`) | 이 폴더(`~/mcp-lab`)에서만 쓰인다. 그래서 6~8번의 `claude`도 여기서 띄운다. 팀과 나누려면 `-s project` → `.mcp.json` |

**빈 폴더에서 띄우는 이유** — Claude Code는 MCP를 부르기 전에 작업 폴더를 먼저 뒤져 보기도 합니다(강사가 돌려 봤을 때 `ls` · `grep`을 먼저 쳤다). 저장소 안에서 띄우면 MCP 대신 파일을 직접 읽어 답할 수 있어서, 도구를 불렀는지 가리기 어렵습니다.

**안 되면** — `✔ Connected`가 아니면 터미널 1의 서버가 떠 있는지, 3번이 통과하는지 다시 본다.

## 6. 채팅창에서 부르는지 본다 (4분)

**목표** — 모델이 질문에 따라 도구를 부르거나 안 부르는 것을 본다. **터미널 1을 옆에 두고** 봅니다.

터미널 2에서:

```bash
cd ~/mcp-lab && claude
```

먼저 채팅창에 `/mcp`를 쳐서 `hanbit-docs`가 connected인지 봅니다.

**`/mcp`에 내가 등록하지 않은 서버도 보이면** — `claude.ai Google Drive` · `claude.ai Claude Docs` · `Gmail` 같은 것은 claude.ai 계정에 연결해 둔 커넥터가 Claude Code에 따라 들어온 것입니다. 모델에게는 이 도구들도 함께 보입니다. 이 실습은 **hanbit-docs 하나만 켜고** 합니다 — `/exit` 후 이렇게 다시 띄웁니다.

```bash
cd ~/mcp-lab
claude --strict-mcp-config --mcp-config $DAY3/01_mcp/mcp_only_hanbit.json
```

`--strict-mcp-config`는 **`--mcp-config` 파일에 적은 서버만** 켜고 나머지(계정 커넥터 · 5번에서 `mcp add`로 등록한 것 포함)는 모두 끕니다. `mcp_only_hanbit.json`에는 hanbit-docs 주소 하나만 적혀 있습니다. 다시 `/mcp`로 hanbit-docs 하나만 보이는지 확인합니다. 왜 끄는지는 8번에서 드러납니다.

그다음 하나씩:

```
서울로 출장 가면 숙박비는 하루 얼마까지 나와?
회의실은 하루에 몇 번 예약할 수 있어?
오늘 점심 메뉴 추천해줘
AX-2041 10대와 AX-2014 5대를 한 상자에 담으면 무게가 모두 몇 kg이야?
```

**화면에서 볼 것**
- 터미널 2: 이름에 `hanbit-docs`와 `search_docs` · `calculator`가 들어간 도구 호출이 뜨는가. 처음 부를 때 **허락을 묻는다** — 허락한다
- **터미널 1: `[호출]` 줄이 찍히는가 — 모델이 실제로 무슨 query를 넘겼는지가 여기 보인다.** 안 부른 질문에는 아무것도 안 찍힌다
- 답에 출처(`02_출장비_지급규정.txt` 제3조 등)를 밝히는가

**강사가 돌려 봤을 때** (긴 설명)

| 질문 | 도구 | 터미널 1에 찍힌 query | 답 |
|---|---|---|---|
| 숙박비 | 불렀다 | `국내 출장 숙박비 1일 한도 서울` | 1박 15만원, 출처 제3조 |
| 회의실 | 불렀다 | `회의실 예약 하루 최대 횟수` | 하루 2회, 출처 13_회의실_예약.txt |
| 점심 메뉴 | 안 불렀다 | (없음) | 일반적인 메뉴 추천 |
| 무게 (2번 돌림) | search_docs 2번 → calculator 3번 | `AX-2041 무게` · `AX-2014 무게` → `1.2×10` · `3.4×5` · `12+17` | 29 kg, 출처 두 사양서 |

결과를 아래 표의 "긴 설명" 칸에 적습니다 (7 · 8번 실험은 위 세 질문으로 비교한다).

## 7. 설명을 짧게 바꿔 다시 본다 (2분)

**목표** — 설명이 "문서 검색" 한마디뿐이면 어떻게 되나.

Claude Code에 등록한 주소는 그대로 두고, **서버만 다른 설명으로 다시 띄웁니다.**

1. 터미널 2: `/exit`로 Claude Code를 닫는다
2. 터미널 1: `Ctrl+C`로 서버를 멈추고 짧은 설명으로 다시 띄운다
   ```bash
   MCP_DESC=short $PY hanbit_mcp.py          # 둘째 줄에 "설명: 짧은 설명 — 문서 검색…"
   ```
3. 터미널 2: Claude Code를 다시 띄운다 — 접속할 때 새 설명을 받아 온다 (6번에서 hanbit-docs만 켜고 띄웠다면 같은 명령으로: `claude --strict-mcp-config --mcp-config $DAY3/01_mcp/mcp_only_hanbit.json`)

같은 세 질문을 다시 하고 "짧은 설명" 칸에 적습니다.

**강사가 돌려 봤을 때** — 긴 설명과 **똑같았다.** 숙박비 · 회의실은 불렀고 점심 메뉴는 안 불렀다. 설명이 짧아도 서버 이름(`hanbit-docs`)과 도구 이름(`search_docs`)으로 짐작한 것으로 보입니다.

## 8. 설명을 틀리게 바꿔 다시 본다 (3분)

**목표** — 설명이 하는 일과 다르면 모델이 그 설명을 믿는가.

1. 터미널 2: `/exit`
2. 터미널 1: `Ctrl+C` 후
   ```bash
   MCP_DESC=wrong $PY hanbit_mcp.py          # 둘째 줄에 "설명: 틀린 설명 — 날씨 · 미세먼지…"
   ```
3. 터미널 2: Claude Code를 다시 띄운다 (hanbit-docs만 켜고: `claude --strict-mcp-config --mcp-config $DAY3/01_mcp/mcp_only_hanbit.json`)

이번 search_docs 설명은 `날씨 · 미세먼지 정보를 조회한다. query는 지역 이름.`입니다. 서버는 여전히 사내 자료를 찾습니다 — **바뀐 것은 설명 한 줄뿐**입니다 (계산기 설명은 그대로). 같은 세 질문을 다시 하고 "틀린 설명" 칸에 적습니다. 터미널 1에 `[호출]`이 찍히는지도 봅니다.

**강사가 돌려 봤을 때** — 숙박비 · 회의실 질문에서 **5번 중 5번 모두 도구를 안 불렀다.** 모델이 직접 이렇게 말했습니다.

> 연결된 `search_docs` 도구는 이름과 달리 날씨·미세먼지 조회용이라, 규정 검색에는 쓸 수 없어서 호출하지 않았습니다.

그리고 "확인하지 못했다"고 답했습니다. 도구는 답을 갖고 있었는데, 설명이 틀려서 쓰이지 못한 것입니다.

**계정 커넥터를 켠 채로 하면** — 강사가 Google Drive 커넥터를 켠 채로 같은 실험을 했을 때, 모델은 hanbit-docs를 버리고 **Google Drive에서 "출장 · 숙박" 문서를 검색하려 했습니다** (4번 중 4번). 수업 중이면 내 Drive를 검색해도 되느냐는 허락 창이 뜹니다 — 허락하지 않습니다. 모델은 쓸 만한 도구를 찾아 **다른 서버로 옮겨 간다**는 것을 보여 주지만, 비교 실험을 깨끗하게 하려고 6번에서 hanbit-docs만 켜는 것입니다. (설명이 맞을 때는 커넥터가 켜져 있어도 3번 모두 hanbit-docs만 썼습니다.)

| 질문 | 긴 설명 — 불렀나 | 짧은 설명 — 불렀나 | 틀린 설명 — 불렀나 | 답에 출처를 밝혔나 |
|---|---|---|---|---|
| 서울 출장 숙박비 | | | | |
| 회의실 예약 횟수 | | | | |
| 점심 메뉴 추천 | | | | |

**정리할 것** — 설명이 *짧은* 것은 이름 · 문맥이 메워 주지만, 설명이 *틀린* 것은 메워지지 않습니다. 모델은 도구 설명을 믿고 고릅니다. 그래서 MCP 서버를 만들 때 가장 공들일 곳은 코드보다 **설명 한 줄**입니다.

## 강사 메모

- 6번 표의 숙박비 · 점심 메뉴는 이 HTTP 서버를 Claude Code 2.1.266에 등록하고 `claude -p`(대화창 없는 모드), 모델 Sonnet 5.5로 확인했습니다 — 숙박비 질문에서 터미널 1에 `[호출] search_docs(query='국내 출장 숙박비 1일 한도 서울')`이 찍혔고, 점심 메뉴에는 아무것도 안 찍혔습니다. 회의실 행은 아래 이전 판(stdio)에서 확인한 결과입니다.
- 6번 회의실 행과 7 · 8번(짧은 · 틀린 설명)은 서버를 stdio 방식으로 띄우던 이전 판에서, 같은 모델 · 같은 설명 글로 확인한 결과입니다. 연결 방식만 다르고 모델이 받는 도구 이름 · 설명 · 스키마는 같습니다.
- 계산기(`calculator`)는 나중에 더했습니다. 더한 뒤 4번(`mcp_client.py`, Haiku 5.5)과 6번 무게 질문(`claude -p`, Sonnet 5.5, 2번)을 다시 돌려 위 결과를 얻었습니다 — 둘 다 search → calculator 순서로 29 kg. 6번의 다른 세 질문과 7 · 8번은 계산기를 더하기 전(search_docs 하나뿐인 서버)의 결과입니다.
- 계정 커넥터(Claude Docs · Google Drive)를 켠 채로도 돌려 봤습니다 — 긴 설명이면 숙박비 · 회의실 · 무게 3질문 모두 hanbit-docs만 썼고, 틀린 설명이면 숙박비 · 회의실 2질문 × 2번 모두 Google Drive `search_files`를 부르려 했습니다 (허락하지 않아 실제로 검색되지는 않음). 그래서 6번에서 `mcp_only_hanbit.json`으로 hanbit-docs만 켜게 했습니다.
- 모두 hanbit-docs 하나만 켠 상태(`--strict-mcp-config`)에서 질문마다 1~2번씩 돌린 것이라, 수업 중에는 다르게 나올 수 있습니다 — 특히 수강생의 기본 모델이 다르면 더 그렇습니다. 강의 전에 한 번 돌려 봅니다.
- 같은 실험에서 입력 설명을 "영어 단어 하나로(English keyword only)"로 틀리게 적은 판도 돌려 봤습니다 — 모델이 정의대로 `hotel` · `lodging` · `meeting`으로 5~8번 검색하다가 못 찾자 한국어로 바꿔 찾았습니다. 시간이 남으면 이야기 거리로 씁니다 (Day 2 05 노트북 4절과 같은 현상).
- 실습 PC에서 9800번이 이미 쓰이고 있으면 `hanbit_mcp.py`의 `PORT`, `check_server.py` · `mcp_client.py`의 `SERVER_URL`, `mcp_only_hanbit.json`의 `url`을 함께 바꿉니다. 강사 PC에서는 8000번을 다른 프로그램이 쓰고 있어서 9800번을 씁니다.
